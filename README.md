# BTO 3D Mockup

Turn Singapore HDB BTO floor plans into quick 3D mockups that homeowners can view in a browser and restyle in different interior themes.

**Status:** planning. No app yet.

## How this project is built

The project follows spec-driven development: every feature is specified and approved before any code is written.

- [Constitution](docs/constitution.md): the rules every feature follows
- [Specs and roadmap](specs/README.md): one folder per feature, with its spec, plan and tasks
- [Glossary](docs/glossary.md): plain-language meanings of the terms used

## Disclaimer

Mockups are indicative only. They are not a substitute for official HDB floor plans or on-site measurement. This project is not affiliated with or endorsed by HDB.
